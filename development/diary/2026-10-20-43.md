## Evidence for the shipped change

Unit and real-`sandbox-exec` tests: decisions for reads, deny-default compilation, parameters only, protections last,
the network on a deny base, git config parsing (quotes, `includeIf`, relative, comments, case), layering, the record.
Real-binary probe P, with a home under `/Users/Shared`: workspace readable, home unreadable to bash and the read tool,
git commits reading an include elsewhere, localhost answers, a fresh Swift package builds and runs, a trusted project
cannot widen, `--read anywhere` widens, and `--continue` without it is restricted again. Probe R: the status label.

Thirteen mutations caught: nine library (two first written in non-compiling forms, re-run compiling), four wiring
through probe P (reads ignored; includes not followed; only one home's tools; the flag not passed).

## Cost

`tools/bash echo, reads restricted`, two runs: p50 10–11 ms, against 9.2 ms sandboxed by default and 2.1 ms unsandboxed.
About 1.5 ms per command for the longer profile, paid only when reads are restricted.

## Mistakes

- **The test world was readable scratch**, again: a home under the temporary directory is inside
  `/private/var/folders`. The fixture can now live in `/Users/Shared` and the suite removes it.
- **A probe expectation contradicted ADR-0045**: after `--read anywhere`, `--continue` is restricted again, because a
  record only narrows. The product was right; the probe now asserts that.
- **Two interrupted runs.** One left a wiring mutant in `ConfigurationSource.swift`; it was found by grepping for the
  mutant and restored before anything else ran. The remaining mutants then ran one per call, each through a script
  that restores on exit, interruption included.
- **The analyzer matched my string tables to another session's.** Rather than add a directive to their file, the
  tables became whitespace-separated text split at load.
- **BSD sed has no `\b`**: the first attempt at the `PathSetting` rename changed nothing. Done in Python.
