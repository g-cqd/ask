# Diary — 2026-10-27 (15)

## Semantic job naming investigation: FoundationModels use cases

Worktree `ask-copilot-parity`, based on 472f73c. Investigated semantic naming
for background jobs using Apple's native `FoundationModels.framework` on macOS 27,
specifically testing the `SystemLanguageModel.UseCase.general` and
`SystemLanguageModel.UseCase.contentTagging` use cases.

### Findings

- Probe script compiled and executed against native FoundationModels APIs.
- `SystemLanguageModel.UseCase.general` produces natural titles:
  `"Dev Mode"`, `"Feature Branch"`, `"Log Watcher"`, `"Python Server"`.
  Latency: 320–450 ms warm (cold call ~1295 ms).
- `SystemLanguageModel.UseCase.contentTagging` is specialized for comma-separated
  keyword extraction (`"development, command, port, npm"`, `"log, monitoring, file, tail"`).
  Even with explicit negative constraints it formats as a comma-separated tag list.
  Latency: 700–850 ms warm.
- Adoption verdict recorded in `development/research/apple-semantic-job-naming-2026-10.md`:
  `contentTagging` is rejected for job titles. Any production adoption of `general`
  must run asynchronously detached from the tool path to respect the 25 ms budget.
