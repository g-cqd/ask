## Faults and gate

8 deliberate faults, 8 killed, each run against a baseline proven green: the lock's name, sharing Codex's lock, no second look, the
account guard (two forms), a lock timeout reported as signed out, a sign-out sentence that does not say what to do, and a retried
failed refresh. Two first attempts proved nothing and were redone: one did not compile, and my first "no second look" fault was
written backwards (the guard returns early when credentials do *not* need refreshing, so I had made the code never refresh); it
failed nearly every test and hung a gated one, which would have counted as "killed" for the wrong reason. The corrected fault is killed.
The analyzers then flagged the Claude/Codex accessors and error enums as clones; accepted at the source with the repo's existing
reason for credential twins. Full gate: **1294 tests** (87 + 193 + 70 + 344 + 600).
