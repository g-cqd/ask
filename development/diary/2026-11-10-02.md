  `ScreenSession`'s unbounded `ScreenEvent` stream. `ScreenController.wheel` applies one step per report; its
  autoscroll timer is for a held drag, not wheel momentum. `MouseEvent` carries no gesture/momentum phase or receipt time.
- `git merge-base --is-ancestor 8abd7e58 HEAD` succeeds: the earlier process-role and screen-executor correction is present.
- **Initial probe:** `python3 /tmp/ask-scroll-interrupt.py`, using the existing main release binary, a local scripted provider,

  erased rather than submitted. It uses `measure-scroll-latency.py`'s PTY, without synthetic CPU burners.
- **Observed:** draft visible after median 76.9 ms, range 60.8–102.0 ms across six attempts. Marker observation polls every

  order is not proof it is the culprit. A real terminal continuing to generate reports, a delayed input queue, and
