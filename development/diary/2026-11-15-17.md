# 2026-11-15 (17): codemode comes first

The owner asked for codemode ahead of what was left of `ask serve`: one script that calls ask's tools, in JavaScript and in
Python, "inspired by pi's integration". Before any design, the evidence: `development/research/codemode-2026-11-15.md`.

| Claim | Probe | Verdict |
|---|---|---|
| pi's codemode is as its documents say | its `CodemodeSandbox` (1.4.0, installed here) run under node on thirteen cases | **Holds**: 17 to 20 ms an execution; an uncaught tool failure fails the script, an unawaited call is cancelled, output before a throw is kept, a promise nothing settles fails at once, `while (true) {}` ends at the deadline, a 64 MB cap gives `out of memory`; no `fetch`, `require`, `process`, timers or `WebAssembly` |
| JavaScriptCore can host the same in ask's process | a Swift probe: a context, a tool as a promise settled from another queue | **Holds**: 2 to 6 ms a context, 0.02 ms a call over 1,000, 100 calls of 30 ms in 40 ms; nothing but `console` and `WebAssembly` exists in it |
| Linking JavaScriptCore costs idle memory | a binary that links it and sleeps | **Fails**: 5.6 MB resident, as Foundation alone. A context is +3 MB |
| A script that never yields can be stopped in process | `JSContextGroupSetExecutionTimeLimit`, exported, not in the public headers | **Holds**, with a catch: the callback is asked once, not again as the header says; re-armed from inside itself it polls, and stopped a spinning script at 0.52 s for 0.5 |
| JavaScriptCore caps memory | a script asking for 4 GB | **Fails**: it got them in 0.4 s. With the watchdog, stopped at +477 MiB against 256 |
| A child interpreter is quick to start | bun, node, deno, python3, each over a JSON-lines bridge, 7 runs | bun 15 ms, deno 25, python3 21 without asyncio and 55 with, node 104, Xcode's `/usr/bin/python3` 158 with asyncio |
| A deny-default profile keeps a child in | bun and python3 under a four-line profile | **Partly**: writes and the network refused, for 6 to 9 ms; that profile still let Python list `~/.ssh` and bun start `/bin/ls`. A real one names the interpreter alone |

Asked with those numbers, the owner chose (ADR-0156): JavaScriptCore in a helper process of ask's; tools only; a script
approved once as a whole; Python with asyncio, on the default runtime; on by default, one tool, JavaScript first.

What the choices settle that the probes had left open: no private call is needed (the child is killed), and the in-process
watchdog is not built. What they cost: ask's start for each script, to be measured as the first step.

`ask serve` is paused where roadmap 0234 says. No code yet.
