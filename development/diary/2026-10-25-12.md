# Diary — 2026-10-25 (12)

## A large server is searched, not listed (ADR-0100, roadmap 0067)

ADR-0099 offered nothing from a server with more than 16 tools. That is the safe default and a poor one for `rea`, which the owner has
configured: 207 tools and no way to see them without reading their names. The answer was two tools, not a bigger limit.

## What was built

`MCPSearch` (ranking, describing, browsing), `MCPCatalog`, `MCPSearchTool`, `MCPCallTool`; the host feeds the catalog and publishes the
two tools while any server is searched; the `skipped` state became `searchable`; `MCPServerStatus.remark` is the one text both the
notice and a one-shot run's stderr use.

## What went wrong on the way

- **A missing `arguments` was an error.** My check for "absent or null" used `isNull`, which is false for a key that is not there, so
  every call with no arguments was refused as "must be an object". Three tests failed, and one failing line in a debug output named it.
  The check now names the wrong kinds (string, number, bool, array) instead of the right ones.
- **A formatter again defeated an unasserted edit.** The report test was rewrapped by `quality.sh`, my replace matched nothing, and the
  build failed on a case I thought I had removed. I looked at the file instead of guessing at the replace.
- **A cut schema can be useless.** The real `rea` schemas start with `$ref`s into a `$defs` that comes later in the text, so a cut at
  3,000 bytes left references that nothing resolves. The budget is now shared, and one tool gets most of its schema.
- The first mutant run left four survivors: name weight (no test separated a name hit from a description hit), the "more" line, wrong
  argument kinds (only a string was tried), and tie order. Three got tests. Tie order is a stable sort in practice; I kept the tie-break
  as a guarantee and said so in the ADR.
- **One-shot runs said nothing** about a searchable server on stderr, because only failures were printed. The remark fixed that, and the
  probe caught it before I did.
