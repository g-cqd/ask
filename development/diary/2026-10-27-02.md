## Context segment

Added a context segment (`25%/200k`) independently prioritized above session spend.
Occupancy is the latest response's uncached input + cache read + cache creation +
reply. It is not the cumulative input count. Compaction invalidates occupancy
until the next measured response, since summarizer usage is not the retained
conversation size. Unknown counts/capacities show an em dash, never zero.
Session replay restores the latest measurement; model changes refresh capacity.
Tool results added since that response are not yet measured by this indicator.

Context accounting and fitting tests pass; `Scripts/quality.sh` is clean.
