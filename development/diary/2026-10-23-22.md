## Implementation evidence

Red first: 327 assertion failures (counting each parameter) against API-only stubs. Then 24 tests in three suites: slicing, adjacent
secrets, exact-first order, repeats, stop characters, `_` and `-`, truncated images, boundary straddling at every alignment 0 to 70
with three chunk sizes, unreadable files, the locator's order, and the verifier's decisions (stop at the first pairing, bounded probes,
every non-pairing answer stops the search, no candidate in any message). One of my tests had a wrong expectation (a longer run also
yields an exact-length prefix) and was corrected, not the code. Two gaps found before mutating: the empty-`PATH`-entry test planted
the wrong path, and no test used `_` or `-`.

Deliberate faults: see the summary below; the driver proves a green baseline first.

## Cost

Baseline is main at `27d158a`, built the same way: **11,252,928 B** against **11,276,784 B** (+23,856), although no startup path
references the new code. Three alternating `measure-budgets.py` rounds of 12 ran at host load 14 to 36, so cold start, input delay
and action delay are **inconclusive** (for example cold start p50 13.0 and 20.3 ms in round 1, 14.7 and 13.1 in round 2, in opposite
directions for the same binary pair). Idle memory, which load does not move, was equal: baseline 9216, 9200, 9208 KiB; feature
9200, 9216 and 9216 KiB (equal within one page). No latency claim is made.
