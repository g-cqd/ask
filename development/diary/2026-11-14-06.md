## Cold start: the owner's decision

Roadmap 0054 found that the share of launches starting on an efficiency core predicts a cohort's median, and left "how budget
verification should treat it" to the owner. Asked with tonight's numbers, the owner chose: **strict, as measured**. A cold-start
cohort over 50 ms refuses the install like any other budget. Consequence, said plainly: on this Mac, in use, an install will be
refused about as often as not, and running it again until it passes would be choosing the best run. A refusal is reported as one.

## Found: a sandboxed command is 97 ms, not 16

With its leg working, `measure-action.py` says a sandboxed `echo ok` reaches the screen in 97.4 ms (p25 96.3, p75 97.8); the diary
of 2026-10-20 (48) says 16–18 ms, and `Budget`'s comment still does. Where it goes, each step measured apart:

| Step | Probe | Cost |
|---|---|---|
| ask with `--yes --no-sandbox`, `/bin/bash`, no shellcheck on the `PATH` | `measure-action`, 10 runs | 8.4 ms |
| The sandbox, same shell and `PATH` | the same with `--yes` | 59.7 ms: **+51 ms** |
| `sandbox-exec` with an empty profile, `/usr/bin/true` | 9 runs | 8.5 ms |
| `sandbox-exec` with ask's profile (dumped from a fixture's settings: 198 parameters, 5,283 bytes) | 15 runs | 50.0 ms: **42 ms is the profile** |
| ...the 198 `-D` parameters with an empty profile | 9 runs | 8.5 ms: the parameters are free, the rules are not |
| ...each rule alone over `(allow default)` | 9 runs each | 102 write protections 29.8 ms; 59 read protections 20.8; 28 ancestors 14.4; 9 write roots 10.1 |
| Homebrew's bash against `/bin/bash`, `-c 'echo ok'` | 15 runs | 9.9 against 2.3 ms |
| The syntax check (`bash -n`) and shellcheck | 15 runs | 9.6 and 22.1 ms (roadmap 0188 knew these) |

In October "an empty profile costs the same as ours" (diary 2026-10-19 (25)); the profile has since gained the other agents'
secrets, the shell's startup files and their ancestors, and `sandbox-exec` compiles it again for every command at about 0.2 ms a
path. Nothing measured it because the leg that would have was not completing. The owner chose to have it investigated next,
