# 2026-11-15 (14): what a served turn says besides words and calls

Roadmap 0234 step 2. Read first (Prompt Turn: "Session notices", "Session compaction", "Session usage updates"; Session List,
"Updating session metadata"; Initialization, the client's `session` capabilities): a `notice` and a `compaction_update` may be
sent only to a client that advertised `session.notices` and `session.compaction` (an object; absent or null is no); a notice
has a severity, a non-empty title and an optional description, and is not replayed; a compaction is one entity under an id of
the agent's, never reused, and one that was reported must be reported as ended; `usage_update` needs `used` and `size` in
tokens; `session_info_update` carries the title, null to clear it.

| Claim | Probe | Verdict |
|---|---|---|
| Each is told as the specification shows it | `ACPSessionUpdatesTests`, a directed conversation saying each | **Holds**: a notice with its first line as title and the rest as description; a compaction begun and completed under one id with what it kept, failed with its reason, cancelled, each with its own id; the title and its clearing; usage in tokens; a call's progress on its title, which it has back when it ends |
| A client that did not advertise is sent neither notices nor compactions | four shapes of "no": `{}`, `session: {}`, both null, `session: null` | **Holds** |
| A name chosen after its turn was answered still reaches the client | the name said after the end, with two other late updates before it | **Holds**: the title is sent, the others are not. Through the real conversation too: Apple's on-device model named the probe's session "help needed", after the first answer |
| The tests can fail | nine mutations at once, then the capability check alone | **Holds**: ten tests red; the capability one alone is caught by the null case |
| A refused message is told why | read `AgentConversation`: a skill that cannot load says its reason, then refuses; a hook that blocks says the refusal, then its reason | **Fails** for the hook's order as built on 2026-11-15 (07): the request got "the prompt was not taken". Fixed: the reason is taken from the error said just before or just after; one never given a reason is answered at the turn's end |
| A failed turn through the real conversation | `probe-serve.py`, part F: the fake provider answers a `permission_error` | **Holds**, three runs: the prompt's error says why, a notice of severity error came before it, the session takes the next prompt. The installed ask, which sends no notices, fails that check |
| Usage through the real conversation | the probe | **Not shown**: the probe's model has no known window, and an unknown count is not sent as zero. `ContextUpdateTests` covers the conversation's side: the update now carries the tokens and the window beside its words |

Decided here:

- **No stand-in for a client that shows no notices.** The specification allows an ordinary agent message instead. ask does not
  write words the model did not say into a conversation; a failure still answers the prompt as an error.
- **Progress is on the call's title**, where the screen has it (the block's header), and the title is given back when the call
  ends.
- **A compaction's id** is `compaction-N`, counted for the session as this connection sees it, replay included.

Not built, and why: a job's output, which comes between turns and needs a watcher the screen starts for itself; a prompt's
pictures; the slash commands. A command is a run of its own (`Conversation.command`), and there are thirty of them, several
of which show a list to pick from, replace the session, or restart the process: which are served, and what a list becomes, is
a design to put to the owner, with the command registry (roadmap 0210) still undecided.
