# Diary — 2026-10-25 (23)

## The server's own stream, and the search ranking judged (ADR-0108)

The last two leftovers of roadmap 0067 that were mine to take. The GET stream was a small extension of the HTTP transport: the
connection already tells the transport when the version is agreed, and that is when the stream is asked for.

## What was built

`HTTPMCPTransport.listen()` and its lifecycle in `negotiated` and `close`; six tests against a played server. No production change to
the ranking: it was evaluated and kept.

## The ranking evaluation

Twelve realistic asks against `rea`'s live 207-tool catalog (names and descriptions, the same substrings the tool searches): **11 of 11
answerable asks put the wanted tool in the top 8.** The twelfth ("import the dwarf debug info") has no such tool in `rea` at all, so
it was not a miss. IDF weighting was implemented in the evaluation harness and did worse (10/12, and it regressed an ask the plain
count got right), so the plain count stays. Top-1 is noisy ("decompile this function" puts `batch_decompile` first) and that is
accepted, because the model reads the whole window with descriptions and schemas.

## What went wrong on the way

- **A stale test binary wasted a mutation run.** The base came out "CAUGHT" and the failures named assertions I had already rewritten.
  I was running a build from before the edit. Rebuilt, and the base was green — the whole run was thrown out and repeated.
- **A race of my own making:** the POST and the GET are both sent asynchronously, so "the last request is the GET" was a coin toss. The
  test now finds the GET by name.
- **A test that proves a negative can't exist here**: "nothing from a 200 text/plain was taken for a message" needs the stream to end to
  return nil, and the base case never delivers, so the check blocks until the time limit. I restructured it, then found the mutant catch
  was a race with `close` and dropped the test; the mutant is recorded in the ADR as equivalent for anything a server plausibly sends.
- Three mutants around the close are recorded rather than caught: the window between the negotiation and the send cannot be forced
  from outside, and one check makes the other's mutant equivalent. Both checks stay.
