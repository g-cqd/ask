# Diary — 2026-10-22 (08)

## The README is for a GitHub visitor; the repo gets a contribution surface

Worktree `ask-readme`, branch `docs/readme-and-github-setup`, from `23d96a6`.
The owner's verdict on the README was blunt, and the probes agreed with him:
it served the resident agent (white paper first, agent instructions, walls of
prose) and told a visitor neither how to get ask nor what was true. The audit
found four stale or wrong claims on the front page, no install story, and a
GitHub setup with one workflow and nothing else.

Restructured: install and screen first, then sandbox, configuration,
providers, extensions (the protocol doc was linked from nowhere), status,
building, contributing. `development/WHITE-PAPER.md` keeps the principles; the
"paste it at the start of any iteration" instruction moved out of the front
page (AGENTS.md is where agents are addressed). Added `CONTRIBUTING.md`
(the external path: quality.sh, evidence rule, gates, commit discipline),
`SECURITY.md` (a repo that stores credentials needs one), and issue templates.
Fixed every defect found. No ADR: the decision is documentation policy for the
one file outside the gated four directories, and the probe ledger below
carries the evidence.
