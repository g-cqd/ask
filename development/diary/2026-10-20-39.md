## Strict modes: write scope and network (roadmap 0042, ADR-0043)

After the nested-sandbox fix (diary 38, `a31763e`), this slice makes the write scope and the network configurable.

## Mistakes

- **An optional enum's `.none`.** `SandboxSection(network: .none)` with `network: Network?` means *unset*, not *no
  network*. Warnings-as-errors stopped it in the tests; production code never writes it that way, and the merge
  now has a named helper rather than nested optional maps.
- **A test expectation, not the code, was wrong**: Foundation's `resolvingSymlinksInPath` strips `/private`, the
  kernel's spelling keeps it. The test now uses `CanonicalPath`.
- **Four probe errors before the probe could be trusted.** (1) The "outside" file was under a temporary HOME, which is
  inside `/private/var/folders`, deliberately writable scratch: it *was* written, correctly. Now `/Users/Shared`.
  (2) `curl -X POST` without a body sent no Content-Length and crashed the fake server's handler (curl 52), which
  looks like a network refusal and is not. (3) Then curl reached the fake *model* server, which counted it as a model
  request and consumed a scripted turn. A separate local server is now the target. (4) A Python edit script
  asserted on a pattern that no longer matched after quoting, aborted, and the next run tested the old probe; the
  edits were then made directly. Each was caught because a check failed for a reason I could explain, not by
  loosening it.

## Cost (ADR-0016)

`config/load` benchmarks, release, before (main's Sources) and after: syscalls 12 and 2 in both; wall p50
105 → 89 µs and 9 → 8.2 µs, quartiles overlapping. No cost claimed and no speedup. A strict profile adds two
Seatbelt rules; the per-command spawn (~8 ms, ADR-0035) dominates and is not re-measured here.
