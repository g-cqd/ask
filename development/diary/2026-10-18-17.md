# Diary — 2026-10-18 (17)

## The yardstick was wrong

Within a day, pi had become the measure: tests began `Diverges from pi`, a source comment said the tree
"mirrors pi's session model", the recovery docs promised "at least as convenient as pi", and the probes
sat in `Scripts/`. The user pushed back. ask is meant to be better overall, more reliable, faster and
lighter, and differing from another agent is not the goal.

They were right, and the cost of the old framing was concrete. A test comment that says how another tool
behaves tells a reader nothing about why ask behaves as it does. Once the other tool changes, the comment
is wrong and no test notices.

## What changed (ADR-0014, superseding ADR-0012)

- Sources and tests name no other agent. Eight markers dropped where the test name already said it all.
  Six recovery-test comments rewritten to give their own reason: one bad line must not cost a session;
  the first duplicate wins because later children were written against it; a summary of messages it
  cannot locate is less trustworthy than the messages.
- The white paper's pi paragraph became "Reliable by default, and never silent", in ask's own terms.
  Still 199 lines.
- Research moved out of the codebase: `development/research/pi-1.3.0-findings.md` and its three probes. Running
  another agent's code stays the method, because it found things reading did not. It is just no longer
  the target.
- AGENTS.md: "Porting from pi" became "Reliability", and the stale "Current state" now lists the real
  targets. README describes ask without reference to another agent.
- ADR-0013's decision stands on its own merits. ADRs and diaries before this keep their wording, as
  history.
