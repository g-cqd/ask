# Diary — 2026-10-18 (14)

## Session tree, with the vacuous test replaced first

The uncommitted draft's compaction test never appended a compaction. It called
`context(afterCompactionAt:)` with an ordinary entry and compared `dropFirst()`, so it passed whether or
not compaction worked. Rewritten before anything landed: context is now derived from the latest
compaction on the active branch, and every context assertion compares the whole identifier list.

`SessionTree` is a value type with typed throws. Branch, checkout, new-root, fork, archive restore and
compaction are all covered, and every failure test asserts `tree == before`, so atomicity is checked
rather than claimed.

## Mutation results

`/tmp/ask-mutate.sh` applies one compiling mutation, runs the filtered suite, and reads the exit status.
It reports BUILD ERROR separately, because a mutation that does not compile proves nothing.

First pass: three BUILD ERRORs and one ESCAPED.

- The BUILD ERRORs were all warnings-as-errors (unreachable code, unused binding). Invalid probes. They
  were rewritten as compiling mutations and all three were then CAUGHT.
- The ESCAPED one exposed real redundancy. `continuing` validated the payload and then also restored
  the leaf in a catch. Removing either half alone changed nothing observable, so neither was tested.
  Kept the single restore path, which covers every error `append` can raise; its mutation is CAUGHT.

Final: 9 of 9 mutations caught. 22 session-tree tests; 43 in AskCoreTests.
