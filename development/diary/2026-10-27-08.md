# Diary — 2026-10-27 (08)

## Unicode spinners and status line layout

User request:
1. Support configurable spinners in `ui.spinner`: `braille`, `braillefull`, `braillequarter`, `snake`, `line`, `dot`, `star`, plus `random` (picked across tool calls).
2. Spinner frames must each take strictly 1 column at all times.
3. Status line layout:
   - Color-coded spinner at the start: white when sandboxed, yellow when not sandboxed, fallback to `!` on idle when unsandboxed, nothing when idle and sandboxed.
   - Ongoing running jobs at the end of the line.
   - Remove `"working…"` string because the animated spinner plays that role.

### Implementation summary

- Added `SpinnerStyle` enum in `AskTUI` supporting `braille`, `braillefull`, `braillequarter`, `snake`, `line`, `dot`, `star`, and `.random` (`resolved()` resolves `.random` into a concrete style; `randomConcrete()` picks uniformly from concrete styles).
- Added `SpinnerPreference` in `AskAgentCore` configuration model for `ui.spinner`, integrated into `UISection`, layered, and surfaced via `RunSettings+Screen`.
- Updated `BlockProgress` and `Transcript` to use configured spinner style for tool and thinking progress indicators.
- Added `StatusLeadingMark` to format leading status line mark: spinner when running (white if sandboxed, yellow if unsandboxed), `!` when unsandboxed and idle, empty when sandboxed and idle.
- Status line composer: removed `"working…"` text, moved runner status segment to the end of segments.
- Screen tick updates `statusFrame` while running so status line spinner animates continuously during running turns.
