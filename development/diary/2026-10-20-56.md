## Mistakes retained

- The first red run for the new types was a compiler failure, not a behavioral test. Do not count it as a mutation.
- The first reset mutant escaped. A nil approver is not the same branch as a user saying no.
- The first PTY Y wait searched for one unwrapped sentence; the terminal wrapped it. The first `/new` result
  check also used the request index before its tool had run. The probe was corrected, then passed twice.
- A request-builder parameter named `context` shadowed the tool context; the compiler rejected it. Use
  `self.context` there.
- GNU `stat` on PATH rejected BSD `stat -f` syntax. This stopped the command before any probe ran, not during
  a probe. Shipping path and size were then checked using Python.
- The structure gate found `AgentConversation.swift` at 251 lines. Removed its redundant file-header doc
  comment (the type already has the complete documentation); the gate then passed without a new exception.
