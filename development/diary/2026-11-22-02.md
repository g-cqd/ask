# 2026-11-22 (2): roadmap 0209, the settings' value types once and each ui setting declared once

The owner put 0209 before MDM (0130) on 2026-11-22. ADR-0166 chose AskCore for the shared value types.

## Step 1: two gates

| Claim | Probe | Verdict |
|---|---|---|
| A file setting one `ui` key shows a value for that key and no other | `UIKeyReadingTests`, one file per catalog row with its example | green on main; **fires**: `tint` read from `separator` fails it (2 issues) |
| Every choice a `ui` setting offers names a case on the screen | `SettingTwinTests` (AskSessionTests), ten pairs | green on main; **fires**: a `faintest` added to the configuration side only fails it |

## The twins go

Ten `*Preference` enumerations and their screen twins became one type each in AskCore (`Dim`, `SessionTint`, `Appearance`,
`InterruptKeys`, `QueuedAfterInterrupt`, `TimeoutDisplay`, `NotifyStyle`, `StatusPathForm`, `StatusPathSide`, `SpinnerStyle`), the
screen's behaviour kept as extensions in AskTUI, which now imports AskCore (`check-layers.py`, the dependency audit). `RunSettings.word`
and the twin test went with the last twin. `SpinnerStyle` keeps `dot` and `star`, marked `isOnlyRead`, drawn as the default as before.
Each move was built and its suites run before its commit. dolly then saw `ConfigurationFile`'s and `UISection`'s field runs as one
structural clone (the type names now alike): accepted where it is.

## Step 2: one declaration per ui setting

`UISetting.all` holds, per key, its catalog row and three closures built from a key path: read from a file, write back as a file
writes it, layer. `UISection.keys`, `value(forKey:)`, `layered(with:)`, the `ui` decoding (with `fold`'s object) and `SettingCatalog.ui`
come from it. First, as its own behaviour change, `ask config` lists the `ui` keys in the catalog's order (red first: an order test).

| Claim | Probe | Verdict |
|---|---|---|
| Behaviour unchanged | AskAgentCoreTests (1,182) and AskSessionTests (90), `config.example.jsonc` compared by `SettingCatalogTests` | green |
| The step-1 gate still fires through the table | `tint`'s declaration pointed at `separator` | 9 issues |
| The cost | a throwaway benchmark, release, 31 samples of 200 parses of the example file, and of 2,000 layerings with one `value(forKey:)`; new and old interleaved, twice | parse: 93.3 and 92.8 µs new against 89.7 and 92.2 µs old (p50), about 1 to 4 %, near the noise; layering plus a lookup: 167 and 153 ns against 111 and 116 ns. Paid once per configuration load: kept |

Not done: the memberwise `UISection.init` and its `@dl:accept` comments (8 in UISection, 15 in ConfigurationFile, against "fewer than
five"); the other sections' declarations, with their merge rules, which MDM needs; adding a setting is now its field, its declaration and
its screen option, plus the docs sentence.
