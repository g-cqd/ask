# Diary — 2026-10-20 (55)

## Thinking folds in the live screen and after resume

Roadmap 0051, ADR-0046. The screen now receives model `thinkingDelta` events, appends them to a thinking item, and starts it folded.
A header click opens one block; Ctrl+T flips the thinking default and clears thinking overrides. Ctrl+O only changes tool blocks.
`ui.thinking` accepts `"folded"` or `"open"`, layers per key, and maps to the screen at startup.

The prompt layout moved unchanged to `ScreenComposer+Prompt.swift` in its own refactor commit before adding the new transcript layout.
The split's release tests: 127 TUI tests and 22 structure tests passed.

### Performance

Command, in `Benchmarks/`: `swift package benchmark --target RenderBenchmarks --filter 'thinking/.*' --no-progress --format text`.
Same release binary, 120×40 screen, 200 earlier items, 400 reasoning lines. These are composer costs, not whole-process latency.

| Work | p25 / p50 / p75 | Allocations |
|---|---|---|
| Unchanged ordinary transcript | 11 / 11 / 11 µs | 3 |
| Unchanged folded reasoning | 11 / 11 / 12 µs | 3 |
| Unchanged open reasoning | 11 / 11 / 12 µs | 3 |
| Append one delta to folded reasoning | 2,832 / 2,888 / 2,957 µs | 881 |
| Open reasoning | 2,621 / 2,658 / 2,710 µs | 1,284 |

An unchanged frame does not rescan the reasoning. Changed reasoning is still scanned to produce the capped display and count; the
2.9 ms and allocation count are a measured cost, not a claim that folding is free. This workload stays below the 5 ms action budget,
but it is not an end-to-end action-budget measurement and makes no guarantee about much larger reasoning text.

### Mistakes caught

- The composer exceeded 250 lines. Prompt layout was split by responsibility, not exempted from the structure gate.
- The first resumed-session review found thinking replay missing. It now has red/green coverage.
- The terminal emulator lacks some regional scroll instructions. As in diary 54, readings after a scroll were fused; the new probe
  requests full position-addressed redraws with SIGWINCH at the same size before inspecting rows.
- A clicked override is not the default. After opening one block by click, the first Ctrl+T opens all blocks, the second folds all.
  The first probe expected the opposite and was corrected to test the documented default-plus-overrides contract.
- The benchmark's filter matches whole names, so `thinking` matched nothing. `thinking/.*` ran the measurements above.
