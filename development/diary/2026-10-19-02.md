# Diary — 2026-10-19 (02)

## The interactive screen, and what measuring it taught

ask with no arguments is now the full-screen agent:
- the transcript, tool status and status line on TerminalKit's `RenderPipeline`;
- Esc or Ctrl-C to abort a turn, which stops its commands' process groups;
- Ctrl-C or Ctrl-D to quit.

A `Conversation` seam keeps AskTUI free of the agent. The session got one shareable owner
(`SessionRecorder`), so a run can be its own task, cancellable for abort.

## Measurement mistakes of mine, each caught before anything was decided on them

- **Startup was "36 ms".** My budget harness ran `import tempfile` in the forked child, timing Python as
  ask. Real: 9.8–20 ms depending on load.
- **"SignalHandler.start takes 8–13 ms".** My own timing `tick` used Foundation's `.formatted()`, whose
  first call loads ICU; the next timestamp paid for it. Integer microseconds showed the screen setup at
  0.25 ms.
- **"The diff costs 87 µs a keystroke".** I composed into a fresh buffer (every cell dirty) and copied the
  front buffer each frame. Through the real `RenderPipeline`, a one-cell flush costs 3 µs.
- **"Abort was not reported", "Ctrl-C did not quit".** Both were the PTY probe searching bytes:
  - a diff renderer never sends a whole changed line, only the changed cells;
  - "ready" was already in the first frame, so Ctrl-C landed mid-turn and correctly aborted.
  The probe now reads the screen through a minimal emulator.

## Real findings

- **An eager URLSession cost 3.4 MiB at launch.** It is now created on first use.
- **TerminalKit's digit table was 393 KB for numbers no terminal uses.** It is now 4 KB, fixed there
  (3440cbd), with an exhaustive test and a side-by-side benchmark.
- **ask's composer was most of a keystroke.** It now composes only what changed: 172 → 42 µs at 120×40,
  671 → 59 µs at 300×80. Input delay went from 0.86 to 0.26 ms.
- **Bracketed paste was never enabled,** so a pasted newline pressed Enter. Fixed, red first.
- **`TextWrap` glued two words** when a line was exactly full ("three" / "fourfive"). Found by a resize
  test; fixed, red first.
- **A mutation of mine wrote `new/dir/b.txt` into the repository.** It made relative paths resolve
  against the process's directory. Removed; a mutation can have side effects outside the code it changes.

## TerminalKit, toward professional grade

Per the user, TerminalKit's own roadmap now carries 0006–0014, each with its evidence: a time benchmark
suite first, then modes as a unit, compact cells, scroll regions, flush proportional to change, input off
the cooperative pool, text layout promoted from ask, Unicode widths against real terminals, and the
pipeline's isolation. ask's 0023 orders them by what ask feels.

## Budgets now

Input delay 0.26 ms, action 0.26 ms, cold start within budget. Idle memory is 16–32 KiB over 8 MiB, from
TerminalKit's cell grids, which scale with the window. That is recorded for 0007's re-derivation rather
than trimmed away.
