### Mutants

Ten mutants of the reader and discovery were run: eight caught outright, the real-path dedupe survived and is *equivalent* in output (two paths to one file
are also two files with identical bytes, which the name-and-bytes rule folds anyway; the real-path rule saves reading each one eight times), and one
survived until a test for blank lines after a block scalar was added, then was caught.

### The provider-neutrality gate

The first layout put the harness table in the core library, and the repository's neutrality gate rejected the word `claude` there. That is the gate working: the
names of other tools belong in the composition root, so the table is `Sources/ask/SkillSource+Harnesses.swift` and the core takes it as a parameter. Tests
use a fixture copy, which the clone analyzer flags; accepted with a reason (a test must not depend on the table it checks).

### Defects the tests found in the first draft

- 50,000 `[` characters overflowed the stack: unbounded recursion in the flow reader. Bounded at 32 levels (and indentation nesting at 48), and the
  test that found it stays.
- A 20,000-key head took 47 seconds: the duplicate-key check was quadratic. A dictionary of positions made it 0.09 s.
- `'It''s: a # not a comment'` lost its tail, because the comment finder did not know that `''` is an apostrophe inside a single-quoted string.
- A heading separated from its paragraph by a blank line was used as the description instead of the paragraph.
- `["agy", "bundled"]` meant "bundled only"; it now means that harness's skills plus the bundled ones.
