First read-only lab pass, Claude Code 2.1.312, disposable ask clone, tools/hooks/MCP disabled in the launcher. The client could reach only

## Established

`GET https://api.anthropic.com/api/oauth/usage` returned HTTP 200, using bearer authentication. The saved response projection has:

| Field | Observed | Meaning/limitation |
| --- | --- | --- |
| `five_hour.utilization` | 2 | Utilization displayed as a percentage; one observation only |
| `seven_day.utilization` | 9 | Same |
| each window's `resets_at` | timestamp | ISO timestamp with offset, retained locally; no reset behaviour exercised |
| `extra_usage.is_enabled` | false | Extra usage disabled for this client's current authorization/account at this time |
| `extra_usage.monthly_limit`, `used_credits`, `currency`, `utilization` | null | No balance or spend conclusion from null fields |
| `spend.enabled` | false | No monetary amount retained by this projection |

The response also contains `limits`, `spend`, `seven_day_breakdown`, `weekly_scoped_shares`, and nullable per-model/product windows. Their
shapes are retained; the initial sanitizer drops arbitrary strings and many numeric fields, so display labels, severity, dollar/minor-unit
values and individual breakdown values are not established. Do not infer the meanings of opaque field names.

Other successful reads returned capability discovery, account-policy flags, organization integration status, referral information and a
bootstrap shape with model options and OAuth account fields. Account values were not retained. Unknown path segments are templated, so
this first export cannot recover their exact endpoint spellings. Resolve through a targeted, reviewed follow-up rather than guessing.

## Inference attempts, not billed observations

Three POST /v1/messages requests were intercepted and blocked before forwarding. They have different body shapes: a minimal request,
a structured-output/title-shaped request, and a conversational streaming request. These may include startup/auxiliary work; the capture
does not establish the purpose of every request. Their local 403 responses say nothing about Anthropic acceptance or billing.

All used bearer authentication, `anthropic-version: 2023-06-01`, `x-app: cli`, and
`user-agent: claude-cli/2.1.312 (external, cli)`. Beta flags differed between the three. The conversational shape includes
`claude-code-20250219`, `oauth-2025-04-20`, interleaved thinking, context management, caching and newer per-turn/thinking controls.
The body includes `metadata.user_id`, multiple system blocks, thinking/context-management settings and safeguards. Only shapes were
saved: exact models, system text and identifiers are not established. Header/body differences from ask are observations, not proof of a
billing discriminator, and copying them blindly is not justified.
