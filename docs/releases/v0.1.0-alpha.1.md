# ask 0.1.0-alpha.1

First versioned, Developer ID–signed and Apple-notarised alpha of `ask`.

## Install

Download `ask-0.1.0-alpha.1-macos-arm64.tar.gz`, verify its SHA-256 against the `.sha256` file, unpack, and put `ask` on your `PATH` (for example `~/.local/bin/ask`). Requires macOS 26 on Apple silicon.

```sh
shasum -a 256 -c ask-0.1.0-alpha.1-macos-arm64.tar.gz.sha256
tar -xzf ask-0.1.0-alpha.1-macos-arm64.tar.gz
install -m 755 ask-0.1.0-alpha.1-macos-arm64/ask ~/.local/bin/ask
```

## Signing

The shipped `ask` binary is signed with a Developer ID Application certificate under identifier `ask` with the hardened runtime enabled and notarised by Apple, so macOS Keychain credentials persist across updates without repeated prompts.
