# Diary — 2026-10-24 (30)

## Roadmap 0043: do the search tools pay for themselves?

Worktree `ask-search`, branch `search-prompt`, from `main`. No Agora. The thinking half of 0043 shipped as 0053; this is the other half,
which says to measure before building. Scripts: `docs/research/search-tools/`. Measured at host load about 20, so absolute times are
inflated and every comparison is within one run of the same machine.

## Probe ledger

| Claim | Probe | Verdict |
|---|---|---|
| A tool saves the spawn cost of `bash rg` | `rg` through `/bin/sh -c`, 25 runs per query on 663 files | Shell alone 6.1 ms; `rg` through it 10.8 to 28.0 ms median. The spawn is real, about a quarter of a small search |
| An in-process search beats it | Throwaway `swiftc -O` benchmark over the same files: enumerate and read, literal scan, `NSRegularExpression`, Swift `Regex` | **REFUTED for regex**: read-everything floor 13.7 ms; literal 13.1 ms (about 10 ms faster than `rg`); `NSRegularExpression` 28.9 ms against `rg` 19.6; Swift `Regex` per line **173 ms** |
| Broad searches flood the context | Output sizes of six queries uncapped and capped at 100 | **CONFIRMED in one case**: `func ` is 2,851 lines, 373 KB, about 93,000 tokens uncapped; the existing 2,000-line / 50 KiB cap leaves about 12,800 tokens; a 100-match cap about 3,500 |
| Models run unbounded searches | Five natural tasks, `ask --print` on Codex `gpt-6.1-sol`, low effort | **PARTLY**: 2 of 5 printed every match (input 20k and 10k tokens against 8k to 14k); 3 used counts or file lists. n=1 each |
| A tool definition is a real per-request cost | Captured an Anthropic request from the shipping binary against a fake server | 8 tools, 5,266 bytes, about 1,300 tokens; one more is about 150 tokens, three about 450 |
| A prompt sentence bounds searches | Binary with the sentence against the one without, interleaved, 3 runs per arm on two unbounded-prone prompts | **INCONCLUSIVE**: 20k to 12k input tokens on one, 23k to 30k on the other; my "bounded" classifier was also crude (it counted any `wc -l`, even when every match was also printed) |

Decision and consequences: ADR-0081. No source file changed; the prompt edit used for the A/B was discarded.
