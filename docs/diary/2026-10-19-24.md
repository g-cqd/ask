# Diary — 2026-10-19 (24)

## Slash commands, and reload of ask's own binary (roadmap 0041, ADR-0034)

The agreed order was configuration, then binary reload. `/reload` needs something to type it into, so slash
commands came first, as a mechanism with the commands that existing machinery could back (`/help`, `/quit`,
`/config`, `/compact`), then `/reload` on top.

### Built

- **A line is a command** only when its first word is a slash and a command-shaped name, so `/Users/me/file`
  stays a prompt. The seam is three members on `Conversation`, so AskTUI still imports no agent.
- **Reload:** `BinaryIdentity` (path, inode, size, mtime), `BinaryWatcher` (kqueue on the directory),
  `SelfCheck` (`--self-check`, killed as a group on timeout), `ScreenExit`, and a close-on-exec sweep before
  `execv --resume`.
- **Evidence for the one design claim that was only reasoning.** I said the terminal must be restored *before*
  `exec` because a process that inherits raw mode would save raw as the settings to restore. TerminalKit's
  `enterRawMode` does save whatever `tcgetattr` returns, so the claim holds. The cost is one flicker.

### The numbers (ADR-0016)

The first watcher used Foundation's `Thread`, and idle memory went from about 8,900 to 9,040 KiB, twice. With the
watcher switched off it returned to baseline, so the thread was the whole cost. `pthread_create` with a 64 KiB
stack removed it: 8,912 and 8,912 KiB against main's 8,912 and 8,896. Cold start, 200 interleaved runs against
main: p50 10.67 → 10.78 ms, with p10 and p90 on either side. The 8,192 KiB budget is already exceeded on
`main` (roadmap 0007), and this does not move it.

### What went wrong, and what each thing changed

- **My first A/B was void.** A `sed` failed on BSD `sed`, so the script compared main against a stale binary from
  another worktree. I noticed because the "new" path in the script still said `ask-long`. The paths are now
  edited in Python, and the script prints them.
- **25 of 25 that proved nothing.** After a failed build I ran the watcher tests with `--skip-build`, which ran
  the old binary. The build failure was in my own output (`close` shadowed by a new method), which I read
  only after the number.
- **Two live runs that never reloaded.** The first wait was `until("ok")`, which my own prompt echo satisfied, so
  `/reload` was typed while the first turn ran and was refused. Everything after "worked" because the session
  simply continued. The status line (`out 4`) and the refusal text on screen gave it away. Every live wait now
  anchors on a line only the model could have written, and the live run also checks the pid is unchanged (an
  `exec`) and that the earlier prompt was replayed.
- **A flaky test I wrote, twice over.**
  - Counting open descriptors process-wide failed whenever another test opened files in parallel. I replaced
    it with `close` returning success, then with checking descriptor numbers, and the latter races for the same
    reason, so the final form asserts only that each `close` succeeded.
  - **The consequence, stated plainly:** a watcher that never closes its descriptors is not caught by design. The
    mutant that removes the `close` calls was "caught" by an unrelated job test failing, which I do not count.
- **A mock that quits at end of input.** `MockTerminalConnection` reports end of input the moment its buffer is
  empty, which the screen treats as a hung-up terminal and quits, racing the command's run. The reload test
  failed 12 times in 25 for that reason, not because the screen was wrong. Closing "after the command's run" is
  therefore proved only on a real terminal (probes H and I), and the unit test checks the controller's state.
- **A port picked from the kernel, released, then asserted free.** Another process took the number once in 40
  runs. The test now discards a port that does not refuse.
- **A commit that failed silently.** I committed with output sent to `/dev/null`, the hook rejected it for
  formatting, and the next command (`git rebase`) refused with "uncommitted changes". The commit step now shows
  the hook's output.
- **Four invalid mutants** (unreachable code and duplicate `case` labels; one reached for a member I had made
  up). Each was rewritten as a compiling expression.
- **The emulator I fixed last session paid off.** The slash and reload probes read several lines of transcript,
  which the old emulator would have drawn over each other.
