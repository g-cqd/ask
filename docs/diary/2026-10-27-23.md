### Behavior

- `ConfigEditor` (AskAgentCore) reads JSON or JSON5 with AemiJSON's
  duplicate-key-refusing JSON5 mode, mapping the raw document through
  `JSONValue` so unknown keys and unrelated settings survive every save.
  JSON5 comments do not survive: AemiJSON re-encodes strict JSON. This is a
  documented consequence, not silent loss.
- Editable rows are the boolean and enum settings: thinking levels, sandbox
  network, all `ui` switches (wire booleans vs `"on"/"off"` strings are kept
  distinct), sidebar, spinner, skills.enabled. Everything else is listed
  read-only so a person can see it exists without the editor guessing at
  strings, numbers, paths or lists.
- Commits re-read the file first, so a change made elsewhere between opening
  and pressing Enter is never overwritten wholesale. The staged display text is
  re-parsed against the file's current value; ask's own validation runs on the
  whole candidate before any bytes reach the disk; project-only restrictions
  (skills on, environment pass) are enforced by that same validation.
- Saves are atomic: a fresh owner-only (or mode-preserving) file beside the
  target, fsync'd and renamed over it, with the directory fsync'd after. The
  file's pretty/compact layout, indent unit, key separator and trailing newline
  are detected and preserved.
- `/config` now takes choices: bare `/config` opens a user/project scope picker
  (the old read-and-show behavior remains at `/config now`). Choosing a scope
  opens the editor: ↑↓ move, ←→ cycle (read-only rows never move), Enter saves
  and keeps the editor open, Escape closes. While open the editor owns every
  key; nothing reaches the draft and no paste inserts text. After a save, the
  conversation's settings are re-read through the existing reload path.
- Project-scope rows carry a trust warning when the file is not trusted as-is.

### Review iterations

The batch was reviewed after implementation rather than testing after each
edit. Issues found and fixed during review: cycling including `unset` in the
wrap direction (now unset is an endpoint, not a pass-through), the boolean/on-off
wire confusion (a JSON5 `tint: 'off'` is a string, not a boolean), one duplicate
re-read in the commit path, Large Tuple/Cyclomatic/TypeBody lint findings
(formatting split into `ConfigEditorFormat`, the write into a single
`ConfigEditor` extension, routing into `ScreenController+Route`), Dolly
near-clone warnings (descriptor tables reduced to `readOnly` helpers with
accepts where tables are data), and a structure-gate offense (nested private
enum folded back into `ConfigEditor`). An indent probe confirmed AemiJSON's
pretty encoder emits Foundation-style `" : "` separators, correcting one test
expectation. A first CLI probe draft assumed ask would start with a config file
it refuses (unknown key); the probe now uses a valid file and checks unrelated
*known* settings survive.

`Scripts/quality.sh --check` is clean (`/tmp/config-quality11.log`): analyzers,
Python suites (14 and 15), Swift targets 295/588/88/78/31/602/870 tests.
