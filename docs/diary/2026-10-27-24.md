### Behavior & implementation

- `SlashCommand.Category` defines the four groups with `.session` as default for
  source compatibility. Built-in and conversation commands are categorized:
  session (help, quit, follow-up, tasks, compact, new, resume, tree, fork),
  model (model, thinking, login, logout), tools (sidebar, verbose, mcp, reload,
  skills), and configuration (config).
- `PickerRow.init(heading:)` represents non-selectable category headings with
  a sentinel marker (`\u{7}heading`).
- `CompletionPicker` computes `choiceIndexes` and `countOfChoices` excluding
  heading rows. `move(_:)` steps only through choice indexes.
  `snapSelectionToChoice()` ensures the selection never rests on a heading upon
  install or filter updates.
- `ScreenComposer.pickerLines` renders headings as dim text (`Style(dim: true)`)
  without selection or choice styling. Label width calculations ignore headings
  so command labels remain aligned. The title count (`1 of N`) reflects
  `countOfChoices`.
- Existing picker controller, composer, click, and skill picker tests were
  updated to reflect grouped presentation, verifying that prefix filtering, Tab
  completion, wheel scrolling, and skill discovery remain completely intact.
