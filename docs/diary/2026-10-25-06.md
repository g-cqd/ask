## Faults

46 faults over the access (expiry boundary, onboarding, the secret rules, every branch of the save), the client (identity, token, project, ids, error path), the
endpoint (header replacement, case, order, path), the settings lines and the thinking refusal. **First run: 36 killed, 3 did not compile, 6 survived.** The survivors
were real:
- the **second-call scenario of a save that keeps failing** never ran, because my test released the lock before it. Two faults hid behind that: "held credentials are not
  used" and "a refresh replaces what is held, not what the file holds". The test now keeps the lock through two calls and checks which record the file ends with;
- **header order** was luck: a two-key dictionary comes out sorted half the time. It has eight keys now;
- **a registration called `agy`** was not tested (one called `codex` was); and
- **the sentences** a person reads on failure were not tested at all.

A sixth was **dead code**: `unsaved.clear()` after a successful save. The next call's settling step clears it anyway (the file no longer holds what the held pair replaced),
so it could not be tested short of a race; I deleted it rather than keep an untested line. Codex's accessor has the same line; I left that alone.
**The final run: all 46 killed**, tree restored by diff. Rebasing onto the other session's notice work (ADR-0091) changed `UnsavedRotation`'s API under me; the accessor
now reports `unsavedReason` and the provider is wrapped like Claude's and Codex's.

Mistakes of mine worth recording: three test helpers did `return Issue.record(...)`, which does not compile in a void function, four times in a row; the
probe script first ran with a relative binary path and a changed working directory; and a comparison of binary sizes against a `main` that had moved on by five
commits was meaningless until I rebased and rebuilt both.
