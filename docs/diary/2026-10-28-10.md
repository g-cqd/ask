# 2026-10-28 (10): 0089, the model filter

`ui.onlyUsefulModels` (default on) hides the models of no use to ask in `/model`, `ask models NAME` and the Codex default. Parsers now
mark instead of dropping (`CatalogModel.unsuitable`), so turning the setting off lists everything. ADR-0125 has the decisions and the
deviation from the roadmap's key name.

Live check with the release binary: `ask models agy` shows the useful models and "5 more hidden (1 image generation, 2 not offered for chat,
2 tab completion)"; `--all` adds a reason column. `ask models codex`: "2 more hidden (2 hidden by the provider)".

A Swift trap met on the way: a `[String: String?]` lookup compared with `== nil` is true only for a missing key, not for a nil value.

Not verified: Copilot live, OpenRouter modality on a real image model, any provider's behaviour with the setting off in a full session.

## The gemini-2.5 thought-signature bug

Reproduced: `gemini-2.5-flash`, `-flash-lite` and `-flash-thinking` answered 400 "Function call is missing a thought_signature" on the
request after a tool call. `AgyThoughtSignature.requiresSignature` now covers Gemini 2.5 and later, so the sentinel is sent. Live after the
fix: all three read a file through the `read` tool and answered. `gemini-2.5-pro` returned 503 "no capacity" on every attempt, so it is
covered by the same rule but was not probed. A tool call after a *signed* reply on 2.5 (a real signature instead of the sentinel) was not
probed separately.

## 0082 and 0095

The `c` came from ask, not the kit: `CSI 99;9u` decodes to `c` with super and the editor typed it. Command chords no longer type; Command and
Ctrl C/X/V copy, cut, paste. The owner asked for the latest pasteboard API: `apple-docs` (macOS 27 corpus) shows NSPasteboard is still it,
with privacy and `accessBehavior` added; SwiftUI's clipboard modifiers need views. Copy moved from `pbcopy` to NSPasteboard too (ADR-0127).
Measured NSPasteboard at about 1 MiB footprint and 2 ms, paid on first use. Option+Backspace/Delete delete by word. New wishes scheduled as
0096 to 0100.
