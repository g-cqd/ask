### Original-block output and completion

ToolOutput now carries explicit background-job metadata (not a prose parser). Agent
updates retain tool invocation IDs; the transcript associates the yielding tool with
its process. A separate cancellable subscription updates only that block's bounded
output and preserves fold choices, independent of the focused lane. Reads do not
advance wait's unread cursor. Background output files survive result consumption;
limits remain the existing per-job 64 MiB file cap and 64 KiB screen tail.

The closing output stream is followed by a final snapshot, so no trailing output or
exit status depends on a notification racing job completion. A completion item is
appended once, faint italic, with leading identity/outcome and trailing frozen elapsed,
actual total line count and status. Run-end cancellation cleanup excludes yielded jobs.
Transcript clearing cancels its subscriptions; unknown/late snapshots cannot populate
another conversation. This process-local association is not persisted across restart:
a restarted ask process cannot resume the old process's jobs.

### Short display identities

Jobs now allocate random four-digit lowercase hex identities under a process-local
mutex. Collisions probe unused four-digit values; a table that exhausts the namespace
falls back to full UUIDs, never reusing a completed job's identity. The strip, focused
lane name, original block and completion use [#hex]. Bash's yielded result includes it.
Internal job-N references remain stable for old tools/scripts; wait/job_input/job_stop
also accept the short identity with or without #. Output file naming/order is unchanged.
