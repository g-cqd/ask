## Faults

82 faults over the decoder, its wire rules, the encoder, its turn builder and the version check; the baseline was proved green first. **First run: 66
killed, 4 survived, 6 did not compile.** The survivors were:
- an **unstarted-stream guard** that the later `throw` already covered (deleted, not tested);
- **empty text emitting an empty delta** into an open block (no test said it must not; now one does, across all six fixtures);
- an **empty user text sent as a part** (the empty-turn test had used an assistant message);
- a version check that **needed no `gemini-` prefix**, since the code stripped seven characters whatever they were: `claude-3-opus` would have counted as Gemini 3 with the
  guard gone. It is in the table now, with `gpt-oss-4`, `3-flash` and `42`.

The six that did not compile were rewritten to compile (an unused `id`, a variable never mutated). The analyzers then forced three changes, each followed by a re-run
of the faults it touches: `decode` was at complexity 11 and was split; the call and result writers were one structure and became one helper (two id faults
became one); and `AgyStreamError` was an exact copy of `OpenAIStreamError`, which the Responses decoder already reuses, so it was deleted. The ceiling of 250
lines then split two test files into six by topic, and **the complete set was run again against the split files: all 80 killed**, tree restored by hash.

Two tests I wrote indexed `events[1]` and `ids[0]` and **crashed the test process** against the stub instead of failing; they use `first` and `dropFirst` now. A
mutation list I wrote also had a pattern for a line that was not there, which the dry run caught before an hour was spent. A poll of mine
timed out while the run was healthy; I read that as a stall before checking the process, and it was not one.
