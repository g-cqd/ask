## Skills, phase 4: a project's skills need trust — roadmap 0061, ADR-0101

### What was built

`SkillDiscovery.discover(…, trust:)` sets a project skill aside (`catalog.untrusted`) unless its real path and bytes are in the trust store; `SkillContents.load` checks
the digest again when it reads; `ask trust --skills` and `ask untrust --skills` (`ProjectSkillTrust`); the report section, the first-prompt notice, the `/skill:` message and
the picker row for a waiting skill; `SkillBook` now looks in project directories.
