## Mistakes

- **The test workspace was scratch, twice more**: the temporary directory is writable and readable in every sandbox, so
  "cannot write beside it" and "outside what the run allows" passed for the wrong reason or failed for it. Fixtures that
  test a boundary now live outside it (/opt for pure rules, /Users/Shared for the real sandbox), and are removed.
- **A baseline that was not one.** Stashing only tracked files left the new source file behind, the baseline build
  failed, and the copy taken as "base" was the new binary: both sides were the same code. Discarded. The baseline is now
  stashed with untracked files, and each binary checked for the new schema's text before measuring.
- A test used `return Issue.record(...)` in a test that returns nothing; a compile error, fixed.
