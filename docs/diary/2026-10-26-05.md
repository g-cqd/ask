- **Xcode's code model** (roadmap 0073, `docs/research/xcode-codelm-2026-10.md`): real and installed (`com.apple.fm.code.generate_*`), reached through private `TokenGeneration`/`ModelCatalog`; inference needs `com.apple.modelmanager.inference`, which AMFI enforces (an ad-hoc signed copy was SIGKILLed; SIP is on). No supported surface found yet; paths to try are in the entry.

Only the groundwork is in code: a row can carry accents and a background filled to the edge (`ScreenComposer.Line.accents`, `spans`). The status line, input below, tints and block model are **not built**.
