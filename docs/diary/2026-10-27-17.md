# Diary — 2026-10-27 (17)

## Consolidation and input ergonomics — first batch

Worktree `ask-tools-consolidation`, based on `6e09c94`. This is a partial delivery,
not completion of the interactive ergonomics study. The study on main remains
an unrelated, untracked file and has not been staged or overwritten.

### Changes

- `write` accepts whole-file `content` or lone `new_text`, or exact UTF-8
  `old_text`/`new_text` replacement. Mixed modes are rejected before filesystem
  access. Replacement delegates to the existing `EditTool` implementation so
  authorization, uniqueness, permissions and atomic writing have one owner.
  Existing `replace_all` remains available. `FileTools.all` advertises read/write,
  not edit. The legacy implementation remains available to library callers.
- `job` exposes input/status/stop, delegating input and group teardown to existing
  implementations. Composition no longer advertises wait/job_input/job_stop.
  Historical transcript records are unaffected; new calls to those removed names
  are not compatibility aliases.
- `bash` accepts output/port readiness waits and an explicit shell. Only shell-tool
  calls select the shell from the filtered launch environment's `SHELL`; an absent
  or nonexecutable value falls back to `/bin/bash`. Internal POSIX scripts retain
  bash, rather than accidentally becoming fish programs. Both restricted and
  unrestricted calls retain the existing process-group and Seatbelt machinery.
  POSIX test fixtures now explicitly select bash, independently of the host shell.
- Tool headers use `tool · summary`; copy/provenance expectations and the folding
  PTY probe follow the same text. Complete input and heredoc presentation are NOT
  implemented by this header-only change.
- Alt arrows and Alt-b/f move by words; Shift+Alt arrows extend/shrink selection.
  Enter on a bare choice-taking slash command opens its choices.
- Accepted queued prompts replace their own tracked slot by prompt ID, not text
  search. A revision guard prevents a cleared transcript's reused index from
  replacing an unrelated item. Late restarts also replace their placeholders.
- Initial skill descriptions are bounded to 80 characters including the ellipsis.
- Clean quit prints the session path and a shell-quoted resume command including
  workspace and launch flags. This is not a new interactive settings editor.

### Red and green evidence

The initial write change was reverted before its new tests were run: 11 tests,
7 issues, followed by implementation and green. Earlier diary wording overstated
red-first evidence for the other initially added features; their initial focused
passes alone did not establish red-first development.

During batch review, new behavioral controls were run before their fixes:

- `/tmp/consolidation-red-review.log`: 21 tests, 5 issues. Mixed write modes modified
  the file; the old advertised tool list still contained edit; shell-tool calls
  ignored the injected `SHELL`. After fixes, write/shell/environment/watchdog
  suites passed together: 36 tests (`/tmp/consolidation-green-review.log`).
- `/tmp/consolidation-queue-red.log`: identical queued text replaced the wrong slot
  and a late restart retained a duplicate placeholder (2 issues). The ID/slot fix
  passes those controls and the existing steering tests.
- `/tmp/consolidation-word-red.log`: Shift+Alt movement failed all three nonempty
  selection assertions. Green: 19 word/input-selection tests together.
- `/tmp/consolidation-skill-red.log`: truncation emitted 81 characters. The fix
  reserves one of the 80 characters for the ellipsis.
- `/tmp/consolidation-port-red.log`: a command exiting before its port opened was
  incorrectly reported as a port timeout. The wait now races readiness, process
  termination and expiry. The test checks exit status, not elapsed wall time;
  it requires its fixture port to be closed rather than accepting another server.

Commands use `swift test -c release --enable-testable-imports --filter ...` to
rebuild tests. `swift build` does not rebuild test executables. Repeated earlier
`--skip-build` runs executed stale code and are NOT evidence about edited source.
The stale test run led to a temporarily reverted shell change; it was replaced
by tested shell selection at the shell-tool boundary.
