## Mutations (nine, all caught, failures read)

Executable, through the real binary: selection never applied; reset keeps the old selection; a refused selection
adopted anyway; a bare id forgets the provider in force; reload drops the selection; self-check without the reload's
arguments. Libraries, through unit tests: selection source mislabelled as a flag; selection leaves the provider
alone; self-check ignores its arguments.

**The third escaped on first run.** The probe passed with a refused selection adopted, because later successful
selections overwrote the bad one before anything observed it. A check was added that runs `/config` straight after
the refusals; with the mutant it reports "Configuration not reloaded" and fails.

## Mistakes

- **A probe that waited on stale text, three times.** (1) A wait matched an identical notice from an earlier
  command. (2) A helper looked for text "below the last `› /config`", but that marker was an older command's.
  (3) When the marker was not on screen yet, `rsplit` returned the whole text, so the old report satisfied it
  and the next command was typed while `/config` ran. Each time the screen said "A turn is still running".
  The helper now requires the marker to be present, and the probe types `/config after-refusals`, which cannot
  match an older line. Three consecutive passes on correct code, then the mutants.
- **A restore that restored nothing.** My mutation loop undid a mutant by editing its replacement text back; for a
  mutant whose replacement was empty the edit was rejected, and the mutant stayed in the tree. I caught it from the
  loop's error, restored the line by hand and checked the diff. The loop now saves the original file and writes it back.
- **A label with an apostrophe broke my shell quoting** and one mutant did not run; it was re-run.
- **`/tmp` was cleaned under me** (by another session or the system): `/tmp/ask-mutate.sh` disappeared. I rebuilt it
  from the version I had read. Disk went from 98% to 89% used at the same time.
- **A structure-gate failure**: an extension of `ResolvedModel` beside `ModelSelection`; moved to its own file.
