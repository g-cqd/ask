## Faults

word and reason code trusted or overlong; a refusal parsed as a body; null project read as none; reasons repeating; any tier id or an overlong one;
a duplicated user-agent header; no token; any status accepted for the list; internal, tab, image and audio entries kept; a bare entry counted as
capable; member-order dependence for the rest and for tiers; repeated ids; any id; zero limits; thinking support dropped; an unlisted default;
an empty list; a non-object entry; command, agent-group and tiered ids not named; a non-object `models`; a refusal without its status.
**All 34 killed on the final run, but the first run showed what the green tests had not**: one survivor (a 41-letter status word, now tested),
and two of mine did not compile, which proves nothing, and one did not apply. The key-sorted fixture would also have hidden both `sorted()`
calls; a test with scrambled members now pins them. Tests that expect `invalidResponse` pass against a stub that always throws it, so they were
trusted only after mutation.
