## The benchmarks earned their keep again

Every first version of a hot path measured badly, each time for the same reason: walking Swift
`String` by grapheme where bytes were meant.

| Path | Before | After |
|---|---|---|
| Output cap, 1 MiB | 14 ms | 0.37–0.50 ms |
| edit, 1 MiB | 20 ms | 1.23 ms |
| read, 1 MiB | 4 ms | 0.57 ms |

Byte matching is also the right semantics for edit: a test that was red on the String version pins
exact-bytes matching.

The loop benchmark found the next real limit. Per-turn work is linear in history and reaches the
2 ms budget near 700 turns; recorded in 0007 with the prefix-cache remedy.

## A correctness hole closed before it shipped

bash commands run in their own session, so that teardown can kill their whole group without signalling
ask. The same property means Ctrl-C at the terminal would kill ask and orphan the command. `-p` now cancels
the run on SIGINT/SIGTERM, so the tool's teardown stops the group, and then exits 128+n. The offline probe
proves it: exit 130 and the backgrounded child dead.
