# Diary — 2026-10-18 (20)

## The provider path starts: AskAI

The user called the pace slow, and the direction is now the shortest path to a usable agent. That means
the Claude streaming path, bottom-up, then the loop.

- **SSE framing** (`SSEDecoder`): WHATWG framing, every byte examined once, whole lines parsed in place
  from the caller's `Span`, only split lines carried. A test re-decodes one stream split at every byte.
  11 mutations caught. One was an *equivalent mutant*: the comment check was dead code, because a comment
  parses as an empty field name that matches nothing. Removed rather than kept untestable.
- **Anthropic events** (`AnthropicStreamDecoder`) into provider-neutral `ModelEvent`s. Shapes taken from
  the official SDK's `RawMessageStreamEvent` types (0.129.0), not from memory. Error events become typed
  `ProviderFailure` kinds. Unknown events, deltas, block types and stop reasons are reported, never
  dropped. 8 mutations caught.
- **Benchmark:** framing 0.60 ms per 2,000 events (272 KiB), framing plus decoding 5.12 ms, about 2.3 µs
  per event. At provider rates that is about 0.02% of a core, so AemiJSON's lazy tape stays a recorded
  candidate, not a detour.

Live recordings wait for ask's own login. pi's stored credentials are not borrowed for fixtures.
