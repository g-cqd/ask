## Focus on a runner: strip keys, a job's output as a lane, Esc back — roadmap 0062 step 2, ADR-0110

### Built

`LaneView` and `ScreenController+Lane` (enter, leave, `onMain`, `deliver`), `ScreenController+Strip` (the keys, click, Esc steps), `RunnerStrip` (rows, selection window, ids for
clicks) and `RunnerTree+Visible` (collapse), `JobTable.outputTail`, `Conversation.runnerOutput`, `Effect.readRunnerOutput`, `ConversationUpdate.runnerOutput`, a revision base for a
lane's transcript, a click region for the strip, the route in the status line.

### Evidence

All 438+ AskTUI tests pass. The probe command became `python3 -u -m http.server` so the job's output reaches the file without a terminal.

### Cost

Frame (layout plus diff, one keystroke, strip open), same harness, old and new executables, three interleaved pairs, load 4.2–4.4 (not idle). 0 runners: 17–18 µs both. 5 runners:
old 21, new 22–23 µs. 50 runners: old 21–22, new 24 µs. About +1 to +3 µs with a strip open (the collapse pass is O(n) per frame); p99 32–36 µs against 28–32. Not free; accepted.
