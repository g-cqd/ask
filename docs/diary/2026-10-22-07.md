## Consequences for the implementation plan

Use native model metadata to choose the thinking mode; do not hard-code a model-name guess or copy a reference client's
level clamping. Claude catalog discovery is an independently useful prerequisite (0038), including its real context/output
limits. It needs credential-free, authorization-scoped caching; no access/refresh token belongs in a model cache.

Continuation was subsequently probed with a real signed thinking block: max effort produced 163 reasoning tokens; reusing
that block unchanged while selecting adaptive low or between_tools for the next completed turn returned 200 in both cases.
Between_tools then completed two fixture echo calls and a final answer over three successful requests, with zero thinking
updates in this sample. No process/file operation occurred. The signed-block-count assertion would fail on a non-thinking
first response, so the binding test did not pass vacuously.

A metadata-only request captured 14 model descriptors with `has_more: false` in an owner-only cache outside the repository
for fixture preparation. Native probe sources are retained in research as `.swift.txt`, not left in the normal test target.
Still to probe: pagination controls and cache invalidation on grant replacement. General OpenAI-compatible services remain
unverified for thinking controls. No quality, cost-saving or latency claim is established by these requests.

## Production slices, October 22

Rebased onto `de9e929`, then `34b18ea`. Main used diary 04 for the measurement-harness investigation while this
research was running; this record moved to 05 before rebasing, and its references moved with it. No other worktree
was edited. The measurement baseline is a separate, detached `ask-thinking-baseline` at `34b18ea`.

The parser uses the native positive flags, not model-name tables. CatalogModel adds optional thinking support and modes
with old-cache defaults. The native client bounds pagination at eight pages/5000 kept descriptors and 2 MiB per reply.
Incomplete pagination retains intact descriptors with a notice, but cannot overwrite a complete cache.
The cache scopes by endpoint, registration and a SHA-256 authorization fingerprint including authorization kind: not a
remote account identity and not the credential. A token refresh intentionally invalidates that token's metadata.

## Cost

Shipping binaries: baseline (`34b18ea`) **10,808,768 B**, feature **11,059,760 B** (+250,992). Idle memory is consistently higher:
baseline 9,648–9,664 KiB, feature 9,840–9,856 KiB (about +0.2 MiB) in every round. Three alternating `measure-budgets.py`
rounds of 12, quiet host (load 5–8): cold start p50 13.9/14.9 and 14.7/13.6 ms, input 0.32/0.30 and 0.26/0.26 ms, in-process action
3.50/3.46 and 3.33/3.50 ms (baseline/feature); within a round neither is slower beyond the spread. Round 3 ran as other agents'
work arrived (cold 24.0/22.9, action 5.3/5.5): both exceeded the action budget together, so it is load, not evidence against
either. A previous full A/B at load 10–16 had the feature at 6.6 and 6.1 ms action in two rounds while its baseline was 4.9; that
is not reproduced under quiet load and is recorded as unexplained, not dismissed. The p95s of both binaries exceeded 25 ms
cold in several rounds under contention. No improvement, and no free-feature claim.
