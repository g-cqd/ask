# Diary — 2026-10-22 (1)

## Finish the selection's copy and click contract

Decision: ADR-0056. Roadmap 0051. Copy-on-select off now has a keyboard path, and selected text does not activate a component beneath it.

- Ctrl+C copies a selection and clears it; the next Ctrl+C keeps the old abort/quit meaning. Escape clears before aborting. A pending
  approval question still owns Ctrl+C, so a selection cannot change the consent workflow.
- A single click inside selected cells clears the selection without opening a fold. Outside those cells, the header can still act.
- The status gives copy/clear instructions while selecting, copy routing/failure feedback after a request, and the measured native
  selection bypass key otherwise. Copy feedback is explicit about sent versus queued; it does not pretend OSC 52 was acknowledged.
- `ScreenClipboard` no longer swallows terminal write errors. Unknown/remote/oversized plans retain the kit's routing rules.
