# Diary — 2026-10-18 (05)

## Blocker 2 resolved in TerminalKit

TerminalKit commit `3f2ccea` establishes the cause: `swift build --build-tests -c release`
did not enable testability, while `swift test -c release --enable-testable-imports` does.
The codec regression passes with that override, including when both original timing flags
are reinstated. Explicitly disabling testability restores the failure.

Reference: TerminalKit ADR-0012 and diary 2026-10-18-03; Apple-docs MCP SE-0455.
The missing-metadata and blanket unsafeFlags explanations were incorrect.

Updated this repository's quality gate to select testability explicitly, superseded ADR-0002
with ADR-0006, and removed the false principle-level timing-flag ban. The remaining expression
type-check flag is unchanged. The user's tighter SwiftLint configuration is unchanged.

Shipping and benchmark builds remain separate ordinary release builds; no byte-identity claim
is made for optimized test builds. Existing public-API tests remain public-API tests.
