# Diary — 2026-10-18 (18)

## AemiJSON and swift-argument-parser, measured before adopted

The user chose the owners: AemiJSON for JSON, swift-argument-parser for the command line. ADR-0015 records
the adoption. Three steps, each committed alone:

1. **Repin TerminalKit to 98650f4.** AemiJSON pins Aemi a6446f1 and SwiftPM allows one revision per package.
   A parallel session had already moved TerminalKit there.
2. **Sessions through AemiJSON.** The wire bytes were unchanged, proved by the golden tests passing as they
   were. Probing the new encoder found a real gap: nothing exercised a `/`, so a mutation turning on slash
   escaping went uncaught. A path test now pins it.
3. **The CLI through argument-parser, and the budget report through AemiJSON**, with a test pinning the four
   keys the measurement script reads.

## The cost was not where I expected

Interleaved PTY runs: before 4.43 ms / 5840 KiB / 0.86 MB; with argument-parser 6.04 ms / 6768 KiB / 2.38 MB;
with AemiJSON as well 6.57 ms / 6928 KiB / 4.69 MB. I had assumed AemiJSON, the big package, would dominate.
It costs mostly binary size. The resident cost is argument-parser's, about 0.9 MiB for one flag. Both stay,
by decision, inside budget. But idle-memory headroom is now about 1.1 MiB with no agent yet, so roadmap 0007
now owes a re-derived memory budget alongside the action budget.

## My own mistakes this round

- **The A/B harness deadlocked the same way the signal probe had hours earlier.** It sent Ctrl-D and then
  waited without draining the PTY, while the child's `tcsetattr(TCSAFLUSH)` waited for exactly that drain.
  Fixed with a drain-while-waiting loop and a hard per-run deadline.
- **Recovering from an aborted probe, I restored `AskTUI.swift` from a stale `/tmp` copy.** That silently
  reverted the committed `stop()`-on-return. Caught by checking the diff before committing, and restored from
  git. Rule from now on: probe targets are restored with `git checkout`, never from a temporary copy.
- One guard probe used a violation that didn't compile, so it proved nothing until replaced with one that did.

New standards rules — `JSONSerialization`, unqualified `JSONEncoder(` / `JSONDecoder(`, `CommandLine.arguments`
— each caught a compiling violation.
