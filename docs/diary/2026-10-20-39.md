### Decision deferred, with its reason

The thinking-level setting (0043) is not built yet. It needs a config key and flag, which means `Configuration.swift`,
`ConfigurationSource.swift` and `AskMain.swift`, all of which the other agent is editing; and the repository forbids shipping
code only tests use, so the request mapping cannot land first and be wired later. Facts gathered for it: Anthropic requests send
**no** `thinking` parameter today; Codex takes `reasoning.effort` from the catalog's own names and has no off; the roadmap's
"off" would have to mean "send nothing, the provider's default applies", which on Codex is not off.

### Merge hazards for the `sandbox-strict` branch (read from its code, not run)

- Its merge base is `32c3d0c`, before all named-connections work, so it faces a real rebase over `ConfigurationSource.swift`,
  `AgentConversation.swift`, `AskMain.swift` and `AgentConversation+Reload.swift`.
- Numbering: ADR 0040, diary 31 and roadmap 0048 exist on both sides with different content.
- Semantics: its `/model` sets `flags.selected` and reloads through `ConfigurationSource.load`. Two rules from ADR-0040 will
  fight it: the resume pin (`flags.provider == nil` keeps a resumed session on its recorded destination, which would override a
  `/model` choice) and the destination consent in `recorder()` (a `/model` that moves a session with history to another
  connection reads as an unapproved change and is refused). A `/model` choice is explicit consent and should count as one.
