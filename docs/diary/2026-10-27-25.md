### Red batch first

`PathDisplayTests` (4 tests), `ToolPresentationTests` (extended), and
`ToolInputPresentationTests` (extended) were written before implementation:
- `PathDisplay.tilde`: replaces `$HOME` prefix with `~`, preserving relative and
  external paths (`/var/folders`, `/Users/other`).
- `PathDisplay.link`: wraps absolute paths into OSC 8 terminal hyperlinks
  `\u{1B}]8;;file://<url-encoded>\u{1B}\<display>\u{1B}]8;;\u{1B}\`.
- `PathDisplay.shellArgument`: keeps plain words, flags (`--resume`, `--no-sandbox`)
  and `~/…` paths unquoted so the receiving shell expands `~`. Unsafe characters
  (spaces, quotes, dollar signs) are escaped with `\` while leaving leading `~`
  unquoted.
- `ToolSummary.header`: formats read windows as `[x:y]` instead of `lines x–y`,
  and formats write sizes as `1 KiB (1,024 B)` or `512 B`.
- `ScreenComposer.toolInputLines`: omits `── input ──` and `── output ──`
  dividers. Input is rendered at default brightness; output is dimmed.
- `ScreenComposer.blockMetadata`: suppresses misleading `"1 line"` count for
  write tool acknowledgements.

### Implementation

- `PathDisplay` in `AskAgentCore/Session`: pure Swift, zero external dependencies.
  Standardizes path resolution, recognizes symlinked `/private` prefixes, encodes
  file URLs with percent encoding, and formats shell arguments safely without
  outer single quotes that would break tilde expansion.
- `AgentConversation.printResumeCommand()`:
  Emits:
  `Session saved to <OSC 8 link to file showing tilde path>`
  `To resume: cd <escaped workspace>; ask --resume <escaped session> <flags>`
- `ToolSummary.header`: uses `[x:y]` for bounded line windows, `[x:]` for open
  offsets, and pure Swift integer/thousand-comma formatting for write byte sizes.
- `ScreenComposer+ToolInput`: removed decorative divider labels. A single blank line
  separates input from output. Input uses `.default` style; output uses `.dim`.
- `ScreenComposer+BlockHeader`: `blockMetadata` takes optional `toolName: String?`;
  when `toolName == "write"`, the acknowledgement line count is suppressed.
