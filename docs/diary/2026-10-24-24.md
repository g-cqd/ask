## Faults

Sign-in layer, **30 killed** against a baseline proven green: scope order, `prompt`, `+` versus `%20`, state width, host, path, port, user
information, `error` parameter, several states, several codes, foreign state, oversized paste, one-character code, a space in a code,
the verifier, a missing refresh token, a refresh dropping the token, the renewal margin, token type, zero lifetime, oversized token,
whitespace in a token, an echoed unknown error code, the ID-token shape, a doubled expiry, a refresh forgetting scopes, a reused
verifier, and the invalid_grant sentence. Three gaps first: user information was shadowed by the password check (a user-only URL
was needed), the 4,096-byte bound was shadowed by the code-length rule (junk in another parameter was needed), and a four-part
"ID token" with a good payload was needed; one fault did not compile and was redone. Storage, **7 killed**: not written, not a known
key, load reads nothing, remove forgets Claude, compare against the wrong value, secret not stored, secret not refreshed. Wiring,
**5 killed**, against the probe: no-candidates path, exit code, logout, URL shown before confirmation, the refusal sentence.
Sources restored byte for byte after each run, verified by hash.

## Duplication the analyzers found

dolly reported my paste parser, token checks and request building as clones of Claude's, Codex's and my own. Three were real shared
concerns, given one owner each under `SignIn/` (`PastedAuthorization`, `TokenSanity`, `JWTPayload`) with Claude and Codex moved onto them
in a separate refactor commit; two were already owned elsewhere (`HTTPRequest.account`, `PlainToken`) and I had not looked, so I
reused them (which also makes the requests say `user-agent: ask`); the rest are accepted twins (the pending sign-in, the closing lines
of two login commands, the state generator, the opening of two paste parsers) with written reasons. One match against the Responses
decoder was a coincidence of long string lists and was fixed by restructuring my test's list. **8 faults in the shared code, 8 killed**
against a baseline proven green; Claude's and Codex's suites passed unchanged.
