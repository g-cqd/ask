# Diary — 2026-10-25 (04)

## `/tree`: going back to before a prompt (ADR-0093)

Second of the two items I took from the re-assessment. ask stores a session as a tree and, until now, offered no way to use it.
Worktree `ask-tree` from `origin/main`.

## What was there, and what was missing

`SessionTree` already had checkout (`moveLeaf`), `activeBranch` and `fork`; the file persisted the leaf; `history()` already replayed
the active branch. Missing: the recorder exposing a persisted checkout, a way to name a point a person can choose, a way to give the
prompt back, and the command.

## Design choices, and why

- **Prompts are the unit.** A person wrote the prompts; replies, tool results and compactions are not things to go back to. Numbers are
  in archive order because that never changes: a listing read a minute ago still means what it said, even after a branch is added. I
  considered numbering in display order and indenting by depth, and dropped it: a branch added later would renumber everything, and
  `(branch after N)` says what an indent would, in words.
- **Go back to *before* a prompt, and give it back.** That is the useful move ("I asked the wrong thing"), and it is what pi does. It
  needed a new update, `fillDraft`, with one rule: never overwrite a draft.
- **Same session.** Unlike `/resume` and `/new`, a checkout does not change which session is open, so it does not drop the model's
  narrowing, the usage totals' meaning, or the jobs; it replays the branch and resets the usage that replay re-adds.

## Mistakes

- My probe waited for words I had misremembered ("go back", the text says "goes back"), and a later step typed a command into an editor
  that still held the prompt I had just returned, so it was sent as a prompt. Both were the probe's fault and the second is a
  reminder of the feature itself: the returned prompt is in the editor until it is cleared or sent.
- `pyte`, the terminal emulator my PTY probes use, had been emptied from `/tmp` (not by me, as far as I can tell), and the first run of
  the probe died with an unhelpful error. Reinstalled with pip.
- The draft rule is nearly unreachable (commands are typed into the editor, which submitting clears); it is there because the
  alternative, overwriting, loses text.

## Not done

branch; none of these is hard, and none belongs inside this change.
