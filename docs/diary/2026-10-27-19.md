### Behavior

- Over 16 eligible skills, the system prompt carries a short search instruction,
  not the catalog. At or below 16, existing maxAdvertised behavior is retained.
- `skill` supports optional query (empty arguments browse), or name for loading;
  combining name/query is refused. Search is at most eight metadata results,
  deterministic, and does not read skill bodies. Source/scope narrowing, trust,
  user-only invocation and shadowing apply before ranking. Names/full descriptions
  are matched; displayed descriptions remain bounded to 80 characters.
- Per-server `maxDirectTools` is nonnegative, including zero. An explicit mode
  overrides automatic thresholding; an explicit tools allowlist is always enforced
  and retains its historical direct behavior in automatic mode.
- MCP searches promote at most eight matching tools per server into live schemas.
  Each subsequent nonempty search replaces that server's promoted set; browsing
  promotes nothing. Listing changes and disconnects withdraw promotions. Promotion
  validates against the current catalog under the same lock as withdrawal, so a
  stale result cannot restore a removed tool. Adapter authorization is unchanged;
  a narrowed-session regression verifies a promoted call never reaches the server.
- Catalog publication weakly captures LiveTools: the registry retains search tools,
  which retain the catalog, so a strong back-reference would create a cycle.
