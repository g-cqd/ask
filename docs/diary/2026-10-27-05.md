content and metadata. Continuations use the full content width. At widths too small for metadata,
the metadata itself is clipped; content continues below without loss. The timer runs only while a
block is live; ASCII animation frames are each one cell. Status is not selectable/copyable.
Only a strict `[exit N]` failure marker yields a numeric code; arbitrary error prose is not put in
metadata. Existing tool output retains error details.

by bash, wait, job_input, job_stop and the focused lane. Existing job tests exercise text waits,

also checks that reading a lane snapshot leaves unread output for native wait.
