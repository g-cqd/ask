# Diary — 2026-10-24 (35)

## Addressing the formal-models report: `wait` no longer finds text the command never printed (roadmap 0057, part one)

Second fault of the report, the one found by the Lean model. Same worktree, one slice per fault, each pushed on its own.

## What was changed

`OutputBuffer.contains(_:)`: where bytes were omitted the head and the tail are two runs with a gap, and each is searched on its own;
where nothing was omitted they are the whole stream, and the join is searched, because there it is real. `Job.wait(for:)` uses it for
its immediate check. `kept` stays for counting and comparing the ends and says in its comment that it is not for searching.

## The real binary

`Scripts/probe-wait-gap.py`: a job prints 1.5 MiB (`Re` ending the first 512 KiB ask keeps, `ad` starting the last 512 KiB, a megabyte
between) while the model is busy in a foreground command, then the model waits for `Read`. The previous binary answers
`[job-1 printed "Read"]`, which the command never printed; this one answers `[nothing happened within 2 s]`. My first version of the
probe passed `yield_seconds: 0.2`, which the tool rejects (an integer), and the control "failed to fail" until I looked at what the
tool had actually said.

## One of my assertions was wrong

I first pinned that `abReadcdz` (keeping 4) does not contain `Read`. The real stream does contain it: the dropped byte is the `a`, so
the buffer cannot see it, which is a false negative the buffer cannot avoid and not behaviour worth locking in. Removed. The line
between "false found" (a defect: the buffer says something the stream does not) and "not found" for a text whose bytes were dropped (a
limit) is the line the fix draws.

## What the report suggested, and what I did instead

The report suggested searching the two runs "with the carry the streaming path already keeps". The carry exists for output that arrives
*after* the wait begins. The immediate check is about output already held, so a carry across the gap would only reintroduce a
text that straddles dropped bytes. Not used.
