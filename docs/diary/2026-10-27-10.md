# 2026-10-27 — Copilot Claude Messages stream termination

## Issue

Inference with Copilot Claude models (e.g. `claude-haiku-5.5`, `claude-sonnet-5.5`) failed at the end of the response with:
`ask: the response stream broke the protocol: malformed(event: "message")`

## Root Cause

GitHub Copilot's `/v1/messages` endpoint implements the Anthropic SSE protocol but appends an OpenAI-style terminal chunk:
```text
event: message_stop
data: {"type":"message_stop"}

data: [DONE]
```
In WHATWG SSE decoding (`SSEDecoder`), an SSE event without an `event:` line defaults to `name = "message"`. When this was passed into `AnthropicStreamDecoder.decode(_ frame: SSEEvent, into:)`, attempting to decode `[DONE]` as JSON failed and threw `AnthropicStreamError.malformed(event: "message")`.

## Fix & Verification

1. In `AnthropicStreamDecoder.swift`, added:
   `if frame.data.elementsEqual("[DONE]".utf8) { return }`
   matching the handling in `OpenAIStreamDecoder`.
2. Added test `a trailing data DONE frame is ignored without error` in `AnthropicStreamTests.swift`.
3. Tested live inference with `ask -p "say test" --provider copilot-vscode --model claude-haiku-5.5` and `claude-sonnet-5.5`: both succeeded with complete text responses and accurate token accounting.
4. Ran full `Scripts/quality.sh`: passed cleanly (865 tests in 115 suites).
